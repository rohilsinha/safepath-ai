# SafePath AI

SafePath AI is a planned mobile platform for safer navigation and emergency response, designed primarily around women's safety. It will help users compare route options using transparent safety evidence, keep trusted emergency contacts, and activate an SOS flow that can share location during an emergency.

## Project status

This repository is at the initial setup stage. It contains the project structure and planning documentation only; no mobile app, API, database schema, AI service, credentials, or dependencies have been created yet.

## Planned capabilities

- Source and destination entry with multiple route options.
- Evidence-based route safety scores from 0 to 100.
- Crime-history, safety-news, and community-review analysis.
- Clear comparison of the safest and fastest routes.
- Community safety reports and reviews.
- Emergency contacts, one-tap SOS, and emergency location sharing.
- Future integrations for push notifications, SMS, voice calling, and device dialling.

## Safety and privacy principles

Safety scores will be calculated from documented, structured evidence rather than generated by an LLM. AI can summarize evidence and explain a recommendation, but it must not fabricate a score or claim certainty unsupported by the data. Location, contact, and emergency data will require deliberate privacy, consent, retention, and security design before implementation.
